# Guide d'utilisation — Plateforme-Agora pour les communes

Depuis le 5 novembre 2026, le mode d'emploi pour les communes n'existe plus qu'en un seul endroit :
la page publique du site, **`frontend/guide-communes.html`**, en ligne sur
https://plateforme-agora.fr/guide-communes.

Elle est liée depuis l'onglet « Ma commune » de l'application et depuis l'email de bienvenue des
mairies. Le guide étant le même pour toutes les communes, une seule page suffit.

**À chaque nouveauté** visible des habitants ou des mairies, c'est ce fichier HTML qu'il faut mettre à
jour, avec sa date de mise à jour en haut de page. Ce Markdown et l'ancienne page publiée sur claude.ai
ne sont plus maintenus.
